## Workspace behavior / privacy boundary

`pkc run` now establishes these product boundaries:

- source-root `CLAUDE.md` is never overwritten;
- source-root `AGENTS.md` is never overwritten;
- no root `knowledge/`, `PKC_KNOWLEDGE.md`, or `PKC_KNOWLEDGE.zip` is generated by `run`;
- legacy `pkc build` retains compatibility outputs;
- repeated `pkc run` replaces generated `.pkc/workspace` so stale generated files do not survive;
- generated paths may not escape `.pkc/workspace`;
- generated `CLAUDE.md` / `AGENTS.md` route Claude/agents through `knowledge/START_HERE.md`, `_policy/answer-contract.md`, and `_meta/catalog.json`;
- PRODUCT is default and does not inspect source;
- TRACE may expose evidence paths/symbols but must not dump source;
- ENGINEERING is explicit and requires approved source-enabled context;
- PRODUCT/QA/benchmark reports must not contain proprietary source-code bodies, secrets, credentials, raw facts, or source-file contents;
- benchmark phase 1 is generated-workspace-only;
- benchmark phase 2 may cross-check source only inside the approved company/source-enabled environment;
- PKC controls generated workspace content/routing but does not control provider/network retention policy;
- proprietary source must therefore be used only with the company's approved Claude Code/enterprise environment;
- manifest remains `PREVIEW`; `pkc verify` / READY-PARTIAL-FAILED is still not implemented.

## Benchmark cadence

Mandatory protocol:

`docs/benchmarks/product-value-benchmark-protocol.md`

Full AI benchmark is **not** an every-edit gate.

```text
Level 0 — deterministic
  default after every change
  focused/related/full tests + build/smoke + deterministic authority/no-leak/output checks
  no AI reread required

Level 1 — targeted AI product-value
  only when a change can alter product answers
  select affected repo/workflow/questions only
  phase 1 workspace-only answer
  phase 2 approved local source cross-check
  score affected dimensions

Level 2 — full AI product-value
  acceptance/release/demo checkpoints
  major canonical knowledge/routing changes
  broad regression risk
  explicit user/reviewer request
```

Do not run the entire pinned AI corpus for a small non-semantic implementation/docs change.
