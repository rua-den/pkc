## Rereview-7 blocker

Rereview 7 demonstrated that same-type method-group projection could validate only the object initializer while ignoring constructor effects:

```csharp
public sealed class Card
{
    public bool IsPublished { get; set; }
    public bool Blocked { get; set; }

    public Card() { }

    public Card(Card source)
    {
        source.IsPublished = false;
    }
}

public IReadOnlyList<Card> GetCards() =>
    _cards
        .Where(card => card.IsPublished)
        .Select(CloneCard)
        .ToArray();

private static Card CloneCard(Card card) => new Card(card)
{
    IsPublished = card.IsPublished,
    Blocked = card.Blocked
};
```

That path could return a clone with `IsPublished == false` while retaining an authoritative rule saying returned items satisfy `card.IsPublished`.
