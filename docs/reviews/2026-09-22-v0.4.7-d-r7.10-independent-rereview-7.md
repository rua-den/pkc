## New compile-valid/runtime-valid counterexample

```html
@if (isAllowed) {
  <!-- { -->
}
<strong>{{ displayPrice }}</strong>
<!-- } -->
```

HTML-comment contents are inert template text. The real Angular `@if` closes before the `displayPrice` interpolation, so the rendered value is not controlled by `isAllowed`.

At `5d43b180...`, `AngularRenderedMemberVisibilityEnricher.FindMatchingBrace` counted `{` and `}` inside HTML comments while locating the matching block brace. The commented `{` increased brace depth, the real closing brace did not close the modeled scope, and the later commented `}` could make the algorithm report a scope extending across the interpolation. PKC could therefore emit a false `ui-member-visibility` fact and downstream R7.10 joint-visibility authority for a value outside the real `@if`.

The violated boundary is exact frontend control-flow scope association. R7.9 render identity can be correct while R7.10 visibility authority is false.
