## New blocker — static inline CSS presentation suppression

Compile-valid/runtime-valid Angular/HTML shape:

```html
<section style="display: none">
  @if (displayPrice > 0) {
    <strong>{{ displayPrice }}</strong>
  }
</section>
```

A static inline `display:none` makes the subtree non-presented to the user. The interpolation therefore cannot serve as proof of an active visible rendered value.

At `97161baa...`, `AngularRenderedMemberAuthorityFilter` rejected comments, tag/attribute interpolation, inert `<ng-template>`, and static `hidden` ancestry, but did not inspect static inline style presentation. The interpolation could therefore still receive `renderAuthority`. `AngularRenderedMemberVisibilityEnricher` could then attach the enclosing `displayPrice > 0` `@if`, R7.9 could create a `rendered UI value` terminal, and R7.10 could create an observable joint-visibility fact.

That would overstate product behavior with claims equivalent to:

```text
Frontend visibility for rendered PriceComponent.displayPrice: visible when displayPrice > 0.
Combined observable visibility ... frontend renders the value when displayPrice > 0.
```

The value is not user-visible because its ancestor is statically `display:none`.

## Violated proof boundary

The violated boundary is the R7.9 phrase:

```text
authoritative active visible Angular text interpolation
```

Exact R7.10 composition IDs can still be internally consistent while the upstream `frontendRenderFactId` itself is over-authoritative. Therefore the generic repair belongs at the rendered-member authority boundary, not in joint composition.

## Regression-first minimum repair

The repair was intentionally narrow:

- reject simple interpolation beneath an active ancestor with static inline `display:none`;
- also support static `display:none !important`;
- compare property/value case-insensitively;
- retain authority for static `display:block`;
- do not interpret interpolated/dynamic style values as static proof;
- do not broaden into `[style]`, `[style.display]`, class stylesheets, computed CSS, other CSS visibility properties, signals, outlets, structural directives, or general runtime DOM semantics.

Regression coverage was added in:

`tests/Pkc.CSharp.Tests/StaticCssRenderAuthorityRegressionTests.cs`

Coverage proves:

1. a static `display:none` ancestor produces no authoritative render and no UI visibility fact;
2. the same shape cannot produce an R7.9 rendered UI terminal or R7.10 joint fact end-to-end;
3. static `display:block` retains the existing positive bounded path.
