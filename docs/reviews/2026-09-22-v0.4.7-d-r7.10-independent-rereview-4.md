## New blocker

Compile-valid/runtime-valid Angular inline template:

```html
<section style="visibility: hidden">
  @if (displayPrice > 0) {
    <strong>{{ displayPrice }}</strong>
  }
</section>
```

The `strong` element remains in layout but its text is visually hidden by the static inline CSS declaration. In this exact fixture there is no descendant visibility override.

That means `{{ displayPrice }}` cannot serve as authoritative evidence for the product-facing statement that the user sees the rendered value.

## Why `dc69e442...` was over-authoritative

At exact `dc69e442...`, `src/Pkc.Frontend/AngularRenderedMemberAuthorityFilter.cs` had a bounded static inline CSS check that recognized only:


Its style-declaration parser did not model `visibility:hidden`.

Therefore the interpolation under the static hidden-visibility ancestor could survive with:



The defect is at the R7.9 observable-render authority boundary, not the backend predicate or R7.10 exact-ID join itself.

## Violated acceptance boundary

R7.9 requires an:

```text
authoritative active visible Angular text interpolation
```

and R7.10 may only compose visibility around that same exact authoritative rendered value.

Static `visibility:hidden` violates the “visible” part of that boundary. The current implementation therefore could overstate PO-facing observable behavior.

## Minimum generic repair

The repair must stay at the render-authority boundary and should not weaken exact identity requirements or add benchmark-specific exceptions.

Required generic shape:

```text
static inline style declaration
→ property visibility
→ exact static value hidden, optionally !important
→ active ancestor is presentation-suppressing
→ no authoritative ui-member-render for descendant interpolation
→ no ui-member-visibility for that render
→ no R7.9 rendered terminal
→ no R7.10 joint fact
```

Positive safeguard:

```text

```

Dynamic/interpolated style values, class-based stylesheets, computed cascade, opacity, scripts and general DOM/runtime behavior are not required by this blocker and must not be guessed.
