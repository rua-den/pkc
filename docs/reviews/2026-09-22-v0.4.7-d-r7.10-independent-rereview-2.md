## New compile-valid/runtime-valid counterexample

The repaired R7.9 render-authority boundary still accepts visible-text interpolation that is inside a statically hidden HTML element:

```html
@if (displayPrice > 0) {
  <strong hidden>{{ displayPrice }}</strong>
}
```

A stronger ancestor form is equally valid:

```html
<section hidden>
  @if (displayPrice > 0) {
    <strong>{{ displayPrice }}</strong>
  }
</section>
```

The standard HTML `hidden` attribute places the element in the hidden state; the browser does not render that element's contents to the user. These templates are valid HTML inside an Angular inline template and are runtime-valid.

This counterexample is distinct from rereview #1. It is not interpolation in a comment, not interpolation in an attribute, and not interpolation under a bare `<ng-template>`.
