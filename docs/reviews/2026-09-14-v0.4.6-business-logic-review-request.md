## Known limitations that must remain explicit

This review candidate does not claim complete business-logic reconstruction for arbitrary code.

Current deliberate boundaries include:

- common expression-bodied LINQ predicates are supported; complex block-bodied predicate lambdas are not yet reconstructed;
- configured-object reconstruction is currently strongest for declarative initializers behind simple source members;
- runtime database values, remote configuration and external-system state remain unknown unless grounded by another evidence source;
- Angular list flow currently covers direct subscription-result assignment and `@for` rendering; stores, RxJS transformation chains, nested frontend filters and richer visibility predicates require further V0.4.7 work;
- DTO/projection/computed transformations that alter observable UI eligibility still need broader cross-layer coverage;
- Azure DevOps input is intentionally not implemented yet.

A reviewer should treat any output that overclaims beyond these boundaries as a blocker.
