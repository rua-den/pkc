## B6.4 blocker from re-review 3

The rejected shape was:

```csharp
_cards
    .Where(card => card.IsPublished)
    .Select(_ => _cards[0])
    .ToArray();
```

The old implementation treated arbitrary LINQ `Select` as preserving the `Where` predicate's returned-item semantics and could synthesize a false inclusion rule.

Required authority boundary:

```text
Where predicate
+ every outer operation proven to preserve the predicate's relevant observable item semantics
→ authoritative inclusion rule

otherwise
→ observed-only / lower authority / no product-level inclusion rule
```

## What changed

`Select` is no longer in the unconditional `Where` pipeline allowlist.

The current implementation accepts `Select` only when it can prove a supported preserving form.

### Direct identity selector

```csharp
.Select(card => card)
```

The returned identifier must resolve to the selector source parameter by Roslyn symbol equality.

### Same-type method-group projection

This narrow proof exists because the known-answer PokeTrade path performs a defensive same-type clone after eligibility filtering.

A method-group projection is accepted only when all relevant conditions are proven:

```text
unique selector method symbol
exactly one source parameter
parameter type == return type
item type is sealed or struct
projector source declaration is available
Where directly reads known stored fields/auto-properties from its source parameter
projector directly returns a same-type object initializer
every predicate-relevant member is copied directly:
    output.Member = input.Member
```

Member rewrite/default/transform/helper indirection or missing proof must reject preservation and downgrade the predicate.

## Adversarial review questions

Challenge at least these classes:

1. **Arbitrary Select**
   - lambda returns a different source item
   - lambda creates a different object
   - lambda changes a predicate-relevant member
   - lambda calls an arbitrary helper
   - indexed Select overload

2. **Identity proof**
   - renamed lambda parameter
   - parenthesized identity expression
   - lookalike identifier from another scope
   - selector whose syntax looks similar but resolves to a different symbol

3. **Same-type method-group proof**
   - copies every predicate member directly: should remain authoritative when proof is valid
   - changes one predicate member: must downgrade
   - omits one predicate member: must downgrade
   - custom computed property in predicate: must downgrade unless semantics are proven
   - non-sealed reference type: must not rely on same-type name alone
   - helper-returned object or multi-statement projector: must not be accepted merely because types match
   - inherited or hidden members: symbol identity must prevent name-only mistakes

4. **Pipeline composition**
   - identity/preserving Select followed by supported materialization
   - non-preserving Select followed by supported materialization
   - multiple Select stages where one is non-preserving
   - other allowlisted receiver operations should not accidentally grant Select authority

5. **Benchmark overfit**
   - production logic must contain no PokeTrade, Mewtwo, Loren or Jellyfin-specific special case

Conservative false negatives are acceptable in V0.4.6. False authoritative Product Owner claims are not.
