## Blocker 1 — unproven component content projection

Counterexample class:

```ts
@Component({
  selector: 'app-shell',
  template: `<span>Shell</span>`
})
export class ShellComponent {}

@Component({
  imports: [ShellComponent],
  template: `
    @if (isAllowed) {
      <app-shell>{{ displayPrice }}</app-shell>
    }
  `
})
export class PriceComponent {}
```

Angular renders child content through matching content-projection slots. If the receiving component does not project the child, the lexical interpolation does not become rendered DOM. The predecessor could nevertheless promote it to authoritative `ui-member-render` and then `ui-member-visibility`.

Regression-first repair:

```text
34182e221df6cf50eaa0ac362a5f575e80236a64
fix: reject unproven Angular content projection
```

The new projection authority filter fails closed beneath component/custom-element hosts when direct content projection is not proven. Product-source component selectors are recognized for element, attribute, class and combined selector forms. Custom-element hosts are conservatively treated as projection boundaries.

Focused regression:

`tests/Pkc.CSharp.Tests/AngularComponentProjectionRenderAuthorityRegressionTests.cs`

## Blocker 2 — non-direct / conditional HTML text containers

Valid Angular templates can contain interpolation whose child text is metadata, browser fallback, or conditionally presented rather than directly page-visible:

```html
<title>{{ displayPrice }}</title>
<canvas>{{ displayPrice }}</canvas>
<dialog>{{ displayPrice }}</dialog>
<details>{{ displayPrice }}</details>
<object>{{ displayPrice }}</object>
<noscript>{{ displayPrice }}</noscript>
```

The predecessor treated ordinary HTML ancestry as enough for direct-text authority and could over-promote these occurrences.

Regression-first repair:

```text
3e6fa7749eb8ef47be4eedb72d1c159cd502692f
fix: bound Angular direct text containers
```

The new HTML direct-text authority filter rejects a bounded metadata/raw/fallback/conditional container set. It deliberately does not claim a general browser/CSS/layout engine. A closed unsupported container does not suppress a later ordinary supported HTML render.

Focused regression:

`tests/Pkc.CSharp.Tests/AngularHtmlDirectTextAuthorityRegressionTests.cs`

HTML descendants inside SVG `foreignObject` remain eligible through the HTML namespace path, subject to the ordinary HTML and projection authority boundaries.
